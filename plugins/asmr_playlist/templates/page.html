ASMR.ONE 收藏抓取 · 插件 id asmr_playlist

把 asmr.one 的公开播放列表或私人收藏抓成可直接导入的 JSON，再用内置 importer {{ importer }} 入库（和上传页/CLI 同一条链路：来源判重、写 import_logs、原始文件存档）。 接口一次给一页作品完整信息（社团/声优/标签/时长/语言版本/评分…），所以不用逐条补详情。

增量适合日常更新（通常只翻 1~2 页）；全量 = 取消上面的勾 + 页码 0；指定范围 = 填页码（可配合增量）。
抓取在后台跑，上方的进度条会实时显示翻到第几页，这期间可以去别的页面。 每页约 {{ form.delay }} 秒 + 请求时间：每页 100 条时，几千条的列表要翻几十页。
保存默认值（接口地址 / 抓取目标 / 认证 / 代理 会自动记住）

密码不会存进配置：勾了「默认抓私人收藏」以后，每次抓取时现填密码， 或者粘一个长期有效的 authorization。

命令行也能干同样的事 
omnishelf plugin asmr_playlist fetch_import \
  --playlist-id <你的播放列表 UUID> \
  --proxy http://127.0.0.1:10809 \
  --pages 0                 # 全量；--no-incremental 表示整段重抓
  # 增量（默认）：页码 0 + 增量 = 抓到底，遇到整页已知就停
  # 只更新最新两页：--pages 1-2
  # 只抓不导入：--dry-run
  # 私人收藏：--target favorites --authorization <Bearer 令牌>
