拷贝漫画书架抓取 · 插件 id copymanga_fetch

把你自己在拷贝漫画书架上的收藏同步下来，存成可以直接导入的 JSON， 再用内置 importer {{ importer }} 入库（和上传页/CLI 同一条链路：来源判重、 写 import_logs、原始文件存档）。书名 / 作者 / 题材 / 连载状态 / 最新话 / 读到第几话 / 更新时间 / 封面 / 详情页地址都会带上。

只抓漫画：书架上的「動畫」在本库里没有对应的类型，抓下来也无处可放。

同步在后台跑，上方的进度条会实时显示翻到第几页，这期间可以去别的页面。 第一次用请先抓一次全量把整个书架落下来，以后用增量就很快。
保存默认值（站点地址 / 认证 / 同步方式 / 翻页参数 会自动记住）

密码不会存进配置：以后每次同步时现填密码， 或者粘一个长期有效的 token。
