拷贝漫画书架抓取 · 插件 id copymanga_fetch

把自己拷贝漫画书架上的收藏同步为可直接导入的 JSON， 再用内置 importer {{ importer }} 导入（与上传页/命令行走同一导入链路）。 书名 / 作者 / 题材 / 连载状态 / 最新话 / 读到第几话 / 更新时间 / 封面 / 详情页地址都会入库。

只抓漫画：书架上的「動畫」在本库没有对应类型，抓取后无处存放。

同步在后台运行，进度条实时显示进度。 首次使用请先跑一次全量同步整个书架，之后用增量即可，速度很快。
保存默认值（站点地址 / 认证 / 同步方式 / 翻页参数 会自动记住）

密码不会保存到配置：以后每次同步时现填密码， 或粘贴一个长期有效的 token。
